# 可视化图表索引

本文件维护本目录下每张图的内容。新增、删除或修改图表时，同步更新此索引及相关数据口径。每个 HTML 只展示一张图，页面内仅保留标题、坐标轴、图例等图表元素；文字说明集中放在本文件。

## 游客变化趋势

使用一张统一的交互式月度游客人数折线图，横轴为月份，纵轴为原始游客人数，使用线性刻度，不进行归一化。不同颜色区分目的地。

点击原有目的地图例，可隐藏对应折线及数据点；再次点击恢复。隐藏时图例淡化，切换显隐不会改变当前坐标范围。图例也支持键盘聚焦后按 Enter 或空格切换。保持原有字体、配色、布局和数据集分界虚线，不添加按钮、工具栏或说明文字。原来的 13 张独立目的地图已移除。

在绘图区滚动鼠标滚轮，可围绕鼠标所在位置放大或缩小；放大后按住鼠标左键拖动可平移查看，双击绘图区恢复完整范围。坐标轴刻度、折线、数据点和分界线同步变化；图例显隐状态在复位时保留。所有交互均在原图内完成，无额外控件。

| HTML 文件 | 图中内容 |
| --- | --- |
| [all_destinations.html](html/all_destinations.html) | 13 个符合筛选条件的国家和地区的游客趋势；点击图例切换折线显隐，共用坐标轴，比较人数规模和长期变化。 |

目的地包括：墨西哥、中国台湾、中国香港、日本、韩国、中国澳门、马尔代夫、柬埔寨、印度尼西亚、新加坡、新西兰、土耳其和澳大利亚；图例名称沿用数据源的英文名称。

### 数据范围与分界

| 阶段 | 时间范围 |
| --- | --- |
| 训练集（Training） | 各图最早的有效观测月份至 2022M07。 |
| 验证集（Validation） | 2022M08–2023M02。 |
| 锁定审核集（Locked audit） | 2023M03–2023M07。 |
| 测试集（Test） | 2023M08–2024M07。 |

三条垂直虚线分别位于 2022M07/2022M08、2023M02/2023M03、2023M07/2023M08 之间；背景色和图例标识各阶段。图中展示完整可用历史（始于 1989M01）至 2024M07，各目的地折线从其最早有效观测开始。

### 数据来源与筛选

- 历史数据：[ISF-TDF2023 公开 CSV](https://raw.githubusercontent.com/tulip-lab/open-data/main/ISF-TDF2023/ISF-TDF2023.csv)，本地缓存为 [data/ISF-TDF2023.csv](data/ISF-TDF2023.csv)，仅使用截至 2023M07 的历史行。
- 测试数据：项目根目录中的 `testset.csv`，仅用于本地实验可视化。
- 筛选条件：测试期 12 个月的数据完整、有限且非负，并且训练、验证、锁定审核三个阶段均有观测。这里的“完整”指测试期完整，不要求历史期没有缺失。
- 历史缺失值不补零、不插值，折线在缺失月份断开。
- 排除 Canada、Chile、USA、Hawaii、Austria、Czech：测试期全部缺失；排除 Thailand：缺少 2023M10、2023M11、2023M12、2024M07。
- [manifest.json](manifest.json) 记录数据文件哈希、入选目的地、排除原因和划分信息。

## 生成与文件职责

在项目根目录运行，无需安装第三方 Python 库：

```powershell
python experiments/visual/generate_trends.py
```

| 路径 | 用途 |
| --- | --- |
| [generate_trends.py](generate_trends.py) | 读取历史与测试数据，筛选目的地，生成全部趋势图和数据清单。 |
| `html/` | 仅生成 all_destinations.html；SVG 和图例交互脚本均内嵌，可离线打开，无外部依赖。 |
| `data/` | 公开历史数据缓存；缓存不存在时，脚本尝试联网下载。 |
| [manifest.json](manifest.json) | 最近一次生成的数据来源、哈希和筛选记录。 |
| [preview.png](preview.png) | 汇总图的浏览器截图，供布局检查；生成脚本不会自动刷新此截图。 |
| [preview_zoom.png](preview_zoom.png) | 放大查看时的浏览器截图，供交互布局检查；生成脚本不会自动刷新此截图。 |

后续新增图表时，应记录 HTML 链接、绘图内容、坐标含义、时间范围、筛选与变换方式、数据来源及生成脚本。修改生成逻辑后重新生成 HTML，并同步更新对应说明；自动生成的 `manifest.json` 无需手工维护。
